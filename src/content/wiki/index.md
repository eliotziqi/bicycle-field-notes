## Start here

For a new journey, use the [trip publishing checklist](publishing/index.md#d-publish-a-trip-article-with-photos). To understand relationships, read [the shared content model](developer/relationships.md). For a failed build or missing photo, use [publishing troubleshooting](publishing/troubleshooting.md).

## Documentation ownership

The Wiki is the detailed source of truth. README introduces the project; AGENTS gives coding invariants; PLAN tracks work and acceptance; CHANGELOG records history. The [documentation policy](developer/documentation.md) explains how to keep them consistent. Compatibility evidence is retained in [CMS validation](developer/cms-compatibility.md); evidence from a local test does not certify a hosted CMS session.
